# شاشة مواقيت الصلاة — تصميم المستخدم

صفحة شاشة مسجد أفقية بتصميم المستخدم: أوقات الصلوات الخمس على المنطقة الفاتحة يسارًا،
وعلى اليمين التاريخ والشروق واسم المسجد والساعة الكبيرة وعدّادا الأذان التالي والإقامة —
نصوص مباشرة على الخلفية، بلا بطاقات ولا أيقونات.

- **البيانات:** `data.js` مولّد من الملف الرئيسي المصحّح `~/workspace/user/files/prayerData.json`
  (167 مدينة عراقية، الحويجة مصحّحة) عبر `generate-data.py`. الأوقات بتوقيت بغداد (Asia/Baghdad).
- **الإعدادات المخفية:** زر الترس أسفل اليسار أو النقر على الساعة — اختيار المدينة (الافتراضي كركوك)،
  اسم المسجد (الافتراضي «مسجد النور»)، دقائق الإقامة لكل صلاة (افتراضي 10)، وتعديل ±30 دقيقة لكل صلاة.
  كلها محفوظة في localStorage.
- **الخطوط:** Alyamama للنصوص العربية و Rubik ExtraBold للأرقام (مضبوطة العرض فلا تهتز الساعة)،
  مستضافة محليًا في `assets/fonts/` (رخص OFL مرفقة).
- **الخلفية:** `bg.jpg` بصورة المستخدم كما هي (1376×768)، تُعرض بتغطية كاملة (cover).
